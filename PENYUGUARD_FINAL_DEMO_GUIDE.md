**Before judges arrive:** Extract the final ZIP; run `START_HERE_WINDOWS.bat`; test the local hero MP4 and its full-width film player. Open `#/demo`. Reset the fictional case data if needed. Set browser zoom to 90–100%, maximize the window, and keep the server command window running.

### Safety and fallback

Do not touch or chase wildlife. The demo doesn't contact authorities. If video playback fails, the bundled poster still shows; the app is fully usable without video. If a live demonstration is interrupted, start at `#/demo` and use the stored case or reset with confirmation. Avoid putting real nesting coordinates into the demo.

### Windows presenter check

The project must be opened from the folder containing `package.json`. No `npm install` is needed. Open `http://127.0.0.1:5173/` if Windows does not open it automatically. The hero uses an original QHD video and the report data is browser-local. The uploaded film's public-use rights must be confirmed separately.


### Visual intro (V5)

Open the homepage on port 5185, point to the QHD looping hero film and show the five-image gallery briefly. The large second video player was removed intentionally; transition from gallery directly to reporting.
