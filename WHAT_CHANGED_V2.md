# PenyuGuard — Premium V2 Design Upgrade

This version preserves the original browser-local case workflow and presents it through a clearer, premium conservation-tech interface.

## Visual enhancements

- Completely revised immersive photo-based landing hero and brand styling.
- New editorial problem/mission story with documented Perhentian Island imagery.
- Redesigned four-stage process, signature Turtle Rescue Passport feature, role-based entry points and conservation ethics statement.
- Four real conservation photographs with clear licenses and caption source information. Image download tool permits genuine offline photography on the user's computer.
- Stronger typography, consistent whitespace, navigation states, cleaner buttons/cards, mobile-specific arrangements and updated footer.
- Photography and improved visual hierarchy across reporting, case passport, demo control room and Insights dashboard.

## Features preserved

All working functions from V1: new incident reporting, input validation, case ID generation, case tracking, passport timeline, role-specific review, response coordination, rule-based suggestions, analytics, printing, local persistence and guided operation demo.

## Run

1. Extract ZIP into any local folder on Windows.
2. Run `DOWNLOAD_REAL_PHOTOS_WINDOWS.bat` once if you want real photos available offline (optional; requires internet).
3. Run `START_HERE_WINDOWS.bat`, or open a terminal **in that folder** and run `npm run dev`.
4. Open `http://127.0.0.1:5173/`.
