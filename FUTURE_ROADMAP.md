# Future roadmap — proposals only, NOT currently implemented

1. **Conservation stakeholder validation** — Interview qualified local conservation practitioners and relevant authorities; map reporting needs and actual review responsibilities. Obtain approvals before real reporting.
2. **React + TypeScript migration** — Rebuild UI modules as typed components, add strict TS models and accessible component primitives. The current dependency-free app can serve as a tested reference for workflows and design.
3. **Production authorization / data protection** — Server-side accounts, role-specific policies, secure storage, audit retention and deletion, incident data redaction, content moderation and abuse prevention.
4. **Shared case coordination** — Authenticated backend, task queue, notifications and case ownership. Avoid dispatch claims until formally integrated with competent conservation agencies.
5. **Safeguarded evidence and sensitive wildlife locations** — Secure image repository with metadata stripping, geospatial access policies, consent and retention rules.
6. **Bahasa Melayu and accessibility audits** — Native translations for reporting and safety, WCAG review with real users and screen readers, cross-device testing.
7. **Carefully evaluated decision support** — Co-design triage rules with qualified practitioners. Any future image-based analysis must be scientifically validated and clearly separated from medical judgment.
8. **Field pilot and impact research** — Measure report quality, time to review, case completeness and operator usability; avoid asserting turtles saved without evidence.
