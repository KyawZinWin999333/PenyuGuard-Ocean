# PenyuGuard V6 — Verified bilingual feature results

## Scope

The V6 codebase is a modification of PenyuGuard Ocean Gallery V5. This verification focused on the navigation-language selector, translation coverage of the site and dynamic workflows, consistency of canonical case data, and regression testing of the existing prototype.

## Automated tests — PASS

Command: `npm run check`

**25 of 25 tests passed** on this build. These cover case generation, verification, case transitions, privacy filtering, dashboard metrics, local persistence, application routes, the image/video presentation, and four new locale tests (persistence, label translations, canonical identifiers, switching to English).

Command: `npm run build`

**PASS.** Creates the deployable static `dist` directory including `js/i18n.js`.

## Chromium browser-interaction harness — PASS

Command: `python qa/bilingual_browser_e2e.py`

**58 of 58 checks passed** using a local in-memory Chromium harness. Selected checks include:

- Navigation language selector changes to Bahasa Melayu and updates the document language.
- Landing page, navigation, reporting form, safety acknowledgement, confirmation and Passport translate into Malay.
- The generalized-area dropdown has a translated visible label but preserves the canonical value used by the domain model.
- A report can be submitted in Malay and receives a unique case ID.
- Review, verification, coordinator assignment, task start, follow-up, case closure, insights and public print view work after switching to Malay.
- Free-text reporter notes and case IDs remain unchanged across language switching.
- Switching back to English restores UI labels without deleting case records.
- The mobile menu contains a functional language selector; 390px and 1440px layouts have no horizontal overflow.
- No uncaught JavaScript exceptions were observed in the harness.

The test log was generated by executed checks, not inferred from presence of controls.

## HTTP checks — PASS

- HTTP 200: main page
- HTTP 200: `js/i18n.js`
- HTTP 206: original QHD video requested with byte range 0–1023 (1024 bytes delivered)

## English ↔ Malay UI coverage audit

The translation audit compared visible DOM text nodes for landing, reporting, tracking, Passport, analytics, demo, reviewer, response, and print routes in both languages. Remaining identical terms are primarily proper nouns (PenyuGuard, Pulau Perhentian, organizational names), case references, numbers, common terms used identically (e.g. status), and brand credits. Custom reporter text is intentionally preserved in the original language.

## Not tested here

- Actual Windows .bat launcher execution in an end-user Windows environment
- Native browser playback of the original QHD MP4 for a full loop
- The operating-system Save as PDF dialog and actual printed PDF file
- Actual multi-device data synchronization (not supported in this demo)
- Rights to publicly republish user-supplied photographs

These limitations do not negate the browser-harness or automated results but should be checked before a public competition presentation.
